# Titanic Dataset – EDA and Data Preprocessing

## Project Overview
This project focuses on inspecting, analysing and preprocessing the Titanic passenger dataset using Python.

## Objectives
- Inspect dataset structure and data types.
- Identify and handle missing values.
- Check duplicate records and data consistency.
- Perform Exploratory Data Analysis (EDA).
- Visualise data using Matplotlib.
- Encode categorical features.
- Scale numerical features.
- Save the prepared dataset as a CSV file.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Scikit-learn

## Dataset
Source: Kaggle – Titanic Dataset

## Project Files
- `Titanic_EDA_Practical.ipynb` – Complete practical notebook.
- `titanic_original.csv` – Original dataset.
- `titanic_prepared.csv` – Cleaned and preprocessed dataset.

## Conclusion
The dataset was inspected, cleaned and transformed through EDA, missing-value handling, categorical encoding and numerical scaling. The final prepared dataset was saved in CSV format for future machine learning workflows.

**Note:** No prediction model was trained.
